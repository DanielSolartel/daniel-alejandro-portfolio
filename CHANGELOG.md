# Changelog

Todos los cambios importantes del portafolio se documentan en este archivo.

## [0.1.0] - 2026-09-12

### Añadido

- Primera versión personalizada del portafolio 3D de Daniel Alejandro Solarte López.
- Presentación profesional, intereses, educación y experiencia práctica.
- Proyecto Lottery Predictor en desarrollo.
- Proyectos académicos Telco Customer Churn y clasificación de imágenes de fondo de ojo.
- Formación ONE relacionada con Java y Spring Boot.
- Diseño responsive con fallback 2D y escena 3D procedural.
- Filtros de certificados, modal accesible y navegación móvil.
- Exportación estática con Next.js.
- Despliegue automático mediante GitHub Actions y GitHub Pages.
